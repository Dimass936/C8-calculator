# С8 Расчеты

Калькулятор по партнёрской программе C8: дивиденды, прогноз прибыли и трастовый фонд.

Один статический HTML-файл — без сборки, без сервера, без зависимостей.
Считает локально в браузере, никуда ничего не отправляет.

## Возможности

| Раздел | Что считает |
|--------|-------------|
| **Дивиденды** | `baseAmount × 0,02 × дни × участники` по уровням C2–C6 |
| **Прогноз прибыли** | 3 режима: до даты / до баланса / до прибыли; конвертация ₽↔USDT |
| **Трастовый фонд** | уровни VIP Траст, ежедневная прибыль, комиссия 30% |
| **Структура команды** | состав участников по уровням C1–C6 |

## Установка на телефон

1. Открыть страницу в Safari
2. «Поделиться» → «На экран Домой»

Запускается полноэкранно, с собственной иконкой.

## Про точность

Деньги считаются не на числах с плавающей точкой, а на `BigInt` в масштабе 1e-8.
Иначе `320 × 0,7` дало бы `224.00000000000003`.
